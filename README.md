# Jaime

Your camera and AI cards, together.

## [Download Jaime for Windows](https://github.com/imranomarr/jaime-downloads/releases/download/v0.1.0-win-beta.3/Jaime-Setup-0.1.0-win-beta.3-x64.exe)

**Full installer · 845 MB · Windows 64-bit**

1. Click **Download Jaime for Windows** above.
2. Close Jaime and camera apps, including Chrome, Zoom and OBS.
3. Open the downloaded file and follow the setup steps.
4. Open **Jaime** from the Start menu. Choose **Open Chat** to type, or **Set up voice** to use your microphone.

The app, virtual camera and local speech files are included.

**Early beta:** Windows may show a security warning because this installer is unsigned. Installation and updates are still being tested.

For Intel or AMD Windows PCs. Windows 11 has not yet been tested; Windows on ARM is not supported.

<details>
<summary>Already have Jaime installed?</summary>

- **Original beta.1:** uninstall **Jaime Private Beta** in Windows Settings → Apps, then install this version.
- **Beta.2 or beta.3:** close Jaime and camera apps, then run the installer.
- If setup reports an existing development camera, use that development installation's removal steps first.

Keep your saved Jaime data. There is no need to delete your settings.
